A. Dasar pemrograman C++

Setiap program C++ dimulai dari fungsi main().

Struktur program

// klik bagian di bawah untuk melihat artinya
#include <iostream>
using namespace std;
int main() {
 int a = 5, b = 7, c;
 c = a * b;
 cout << c;
 return 0;
}
Pilih salah satu tombol.

B. Struktur kontrol

Program memilih jalan berdasarkan kondisi. Ubah angkanya dan amati baris mana yang dijalankan.

if bertingkat: diskon buku

Kondisi diperiksa dari atas. Yang pertama benar dijalankan, sisanya dilewati.

switch-case

switch (pilihan) {
 case 1: cout << "Satu"; break;
 case 2: cout << "Dua"; break;
 default: cout << "Tidak ada";
}
default jalan bila tidak ada case yang cocok. break keluar dari switch.

Perulangan for



Mulai i=0, selama i<batas, tambah 1 tiap putaran. Jadi i terakhir adalah batas dikurangi 1.

Perangkat jaringan

D. Model OSI dan protokol IP


Klik lapisan untuk melihat fungsinya. Aktifkan mode tebak untuk berlatih menghafal.




    

    Pengingat urutan dari atas: Application, Presentation, Session, Transport, Network, Data Link, Physical.
    

    

    Alamat IP (Layer 3)
    Identitas logis perangkat. Router memakai alamat IP untuk meneruskan paket antar jaringan.
    

    MAC Address (Layer 2)
    Identitas fisik unik pada NIC, dipakai untuk mengenali pengirim dan penerima.
